# Teixeira Stones — Painel de Leads & Vendas

Site estático (um único `index.html`). Não precisa instalar nada nem rodar build.

## Subir no GitHub
1. Crie um repositório novo (de preferência **privado**), por exemplo `ts-stones-dashboard`.
2. Envie os arquivos desta pasta: `index.html`, `favicon.png`, `vercel.json` e este `README.md`.

## Publicar na Vercel
1. Na Vercel, clique em **Add New → Project** e importe o repositório.
2. Em **Framework Preset** escolha **Other**. Deixe o *Build Command* vazio e o *Output Directory* como está (raiz).
3. Clique em **Deploy**. Pronto: o painel abre no endereço que a Vercel gerar.

Cada vez que você atualizar o `index.html` no GitHub, a Vercel publica a nova versão sozinha.

## Importante sobre os dados
- O que for digitado fica salvo **no navegador de quem digitou** (cada computador/celular tem a sua cópia).
- Para levar os dados para outro computador ou para o cliente: **Salvar backup** → no outro navegador, **Abrir backup**.
- Ao abrir pela primeira vez, a planilha já vem com os dados de 2025 e 2026.
- O site está marcado para não aparecer no Google (noindex), mas quem tiver o link consegue abrir.
